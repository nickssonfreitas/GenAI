## Steps to Run Ollama and OpenWebUI with Docker Compose

1. **Clone the Repository**
    ```sh
    git clone https://github.com/nickssonfreitas/genai
    cd ollama
    ```

2. **Create a `.env` File**
    Create a `.env` file in the root directory with the following content:
    ```env
    OLLAMA_IMAGE=ollama/ollama:latest
    OLLAMA_CONTAINER_NAME=ollama
    OLLAMA_LOCAL_DATA_VOLUME=/home/nicksson/app/ollama-data
    OLLAMA_PORT=11434
    OPENWEBUI_IMAGE=ghcr.io/open-webui/open-webui:latest
    OPENWEBUI_CONTAINER_NAME=openwebui
    OPENWEBUI_PORT=3000
    OPENWEBUI_DATA_VOLUME=/home/nicksson/app/open-webui-data
    OLLAMA_BASE_URL=http://ollama:11434
    ```

3. **Run Docker Compose**
    Execute the following command to start the services:
    ```sh
    docker-compose up -d
    ```

4. **Verify the Services**
    Check the logs to ensure that both services are running correctly:
    ```sh
    docker-compose logs ollama
    docker-compose logs openwebui
    ```

## Steps to Install Models Using `install-ollama-models.sh`

The `install-ollama-models.sh` script is automatically executed when the Ollama container starts. It installs all necessary models directly within the container.

1. **Verify the Installation**
    Ensure that the models are installed correctly by checking the relevant directories:
    ```sh
    docker exec -it ollama ls /root/.ollama/models
    ```

By following these steps, you will have both Ollama and OpenWebUI running, and the necessary models installed in the Ollama container.
